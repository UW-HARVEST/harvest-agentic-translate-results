# Configuration Surface

## Build-Time Configurations

`Cargo.toml` has no `[features]` table, and `c_src/CMakeLists.txt` declares no
options or conditional sources. The complete feature matrix therefore has one
valid member:

| # | Cargo invocation | CMake configuration | |
|---|------------------|---------------------|-|
| B01 | `--no-default-features --features ''` | default, position-independent shared library linked with `libm` | [x] |

For `doubleneg`, each nonzero slot is randomized across positive and negative
values. This exercises the nested division/exponent path, byte-generation
casts, all four searches, direct `memchr`, and the ten-iteration combined
search through the public top-level entry point.
