# Configuration Surface

## Build-Time Configurations

`Cargo.toml` has no `[features]` table and `c_src/CMakeLists.txt` has no build options.
There is exactly one valid combination: `cargo --no-default-features` (empty feature set), matching the prebuilt `pnglibconf.h` configuration.
