# Configuration Surface

Cargo declares no features, so the complete Cargo feature powerset is the default build and the equivalent `--no-default-features` build. The C feature configuration is fixed by `c_src/include/pnglibconf.h`.

One row per dynamic C entry point/table. Function rows are derived from `nm -D` and the defining C source. Tests exercise branch-relevant shape classes with fixed-seed inputs: empty/one/many, minimum/maximum/one-past scalars, valid/NULL pointers where the C checks them, all documented enum modes, and direct plus composed read/write paths.
