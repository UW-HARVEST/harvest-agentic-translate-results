# CONFIGS.md — CONFIGURATION-SURFACE TABLE (valid inputs)

Every row is a configuration the C code actually distinguishes, derived
mechanically from the branches in the C source. Phase B requires each row to
pass a differential test across many randomized inputs before it is checked.

Row numbering is global and continuous across sections.
